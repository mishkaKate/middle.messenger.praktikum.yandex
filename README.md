# Чат на Vanilla JS 

Учебный проект.

## Что он делает

Основная задача — практическое применение теории.

## Установка

Чтобы начать, выполните:

```bash
git clone https://github.com/mishkaKate/middle.messenger.praktikum.yandex.git
cd repo
npm install
npm run start
```
Проект будет доступен по адресу http://localhost:3000/
